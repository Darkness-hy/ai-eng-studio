### 1.1 与「② 等距主视觉」的边界

Q3 含「2D/等距新视觉」，在方案 A 下解释为：

- **主体验**：3D 岛  
- **等距/2D**：世界地图模式、加载/过场、弱设备 `renderer=2d` 回退、宣传静帧  
- **不做**：把主循环改成纯等距点建筑（那是方案 C）

若日后要升格等距为主，需另开决策，不在本文件默认路径内。

## 2. 产品一句话（界面层）

> 你在一座**看起来像真实研究园区**的岛上走动与遇见人；需要时才打开卷宗。  
> 探索和对话给「想玩」；卷宗给「破案与 L1」——两者不抢主屏。

## 3. 屏幕与层级（信息架构）

### 3.1 层级从底到顶

```text
L0  3D 世界（主屏，永远在）
L1  常驻极简 HUD（场景名 / 一句探案提示 / 卷宗按钮+完整度点）
L2  接近交互提示（按 E · 检视海报）
L3  情境叠层（对话 / 线索卡 / 实验工位）——深色半屏，不跳路由
L4  卷宗板（按钮开关，全屏或大抽屉，深色，可关回岛）
L5  系统（地图、设置、退出）——少而静
```

### 3.2 明确禁止（相对当前痛点）

| 禁止 | 原因 |
|---|---|
| 点「打开卷宗」→ 整页白底站外跳转 | 破坏空间沉浸与探索欲 |
| NPC 对话弹出高对比白卡片/金边玩具框 | 破坏角色戏份 |
| HUD 信息墙（多条 ALL CAPS、多进度条） | 抢探索注意力 |
| 卷宗常驻半屏 | 与 Q1「主屏=世界」冲突 |

### 3.3 卷宗开关契约

- **开**：岛上按钮 / 快捷键（建议 `J` 或 `Tab`）/ 关键任务需要时软提示  
- **关**：明确「返回岛上」，相机与输入立刻回 L0  
- **状态**：开卷宗时暂停移动（或大幅降敏），避免一边走一边填表  
- **数据**：仍写同一 `caseStore`（D6）

## 4. 想玩双引擎怎么落到界面

### 4.1 空间探索欲

界面只**指路不剧透**：

- 线索用**世界吸引子**（灯、声、剪影、微粒子），少用大地图图标轰炸  
- 软门槛用「听不懂 / 锁着的抽屉」叙事，不用灰色任务列表  
- 地图模式（可 2D/等距辅视觉）：只标已发现与当前建议方向  

### 4.2 角色 / 对话

对话是**第二主角**，不是系统菜单：

- 底部或下三分之一深色对话层，立绘/半身在场景一侧  
- 导师门控、审稿压力都走对话层 + 结果回写卷宗  
- 选项少而重（说清矛盾 / 含糊请教），避免 RPG 商店式按钮墙  
- 角色造型、音色、日程（中后期）服务「想见这个人」

## 5. 视觉方向（成年 3D，不绑现有灰盒资产）

### 5.1 目标气质

**安静研究园区 · 阴天或清晨 · 低饱和 · 成人比例 · 建筑可读**

参考气质（借神不借皮）：

- 空间：大学科研园 / 北欧校园 / 博物馆园区  
- UI：编辑式深色叠层（与主站 editorial 同源，但游戏内用深色）  
- 角色：写实简化或低多边形**成人**，不是 Q 版吉祥物  

### 5.2 明确不做

- 高饱和六色角色、金色描边 UI、圆角糖果按钮  
- 乐园式植被与玩具灯 emissive  
- 「RESEARCH ISLAND · 3D」展示型英文大写墙  

### 5.3 美术替换策略（可并行于代码）

| 层 | 策略 |
|---|---|
| 白盒 | 先比例与剪影正确（门 2.1m、路宽、建筑层高） |
| 中盒 | 统一材质包：混凝土 / 玻璃 / 金属 / 暖木（室内） |
| 高盒 | 少量关键 GLB（学院穹顶、机房一排、广场雕塑） |
| 角色 | 2–3 个可复用成人 rig + 换色袖标（导师/审稿） |
| 2D 辅 | 地图、加载、宣传：同一色板的等距或线描 |

资产来源可混：自研程序化 + 采购/生成（含 Meshy 类）+ 手调；**验收看静帧是否想点进**，不看管线出身。

## 6. HUD 与对话线框（文案级）

### 6.1 常驻 HUD（尽量空）

```text
左上：场景中文名
      一句下一步（矛盾未解 / 去找导师…）
右上：地图 · 卷宗(● 62%) · 菜单
下中（仅靠近时）：[E] 检视 · 广场海报墙
```

### 6.2 对话层

```text
┌─────────────────────────────────────────┐
│  (场景仍隐约可见)                         │
│                                         │
│  [半身]  苏老师 · 方法导师                 │
│          先说清海报和复现哪里对不上……      │
│          [说清矛盾]  [含糊请教]  [离开]     │
```

```text

左：现场摘要 / 证据列表
右：主张与连边 / 送审 / 导出 L1
```

## 7. 分阶段执行（建议）

### Phase 0 · 壳层定死（约数日，少美术）

- 卷宗**只**以岛内开关叠层出现（路由 `/research-game/case` 可保留深链，但岛内主路径不跳白页）  
- HUD 减到 6.1  
- 对话/线索/实验统一深色 L3，去掉金边玩具 CTA  
- 字号保持可读下限  

**验收**：录屏 30 秒，无整页白跳、无突兀白对话框。

### Phase 1 · 3D 白盒成年比例（1–2 周）

- 单一 campus 场景做深：路网、3–5 个强剪影建筑、正确人尺  
- 室内可暂用「门后淡入小空间」  
- 吸引子与 POI 绑定案件 demo  

**验收**：静帧不说明文案时，仍像「园区」而非积木沙盘。

### Phase 2 · 角色与对话戏（并行）

- 导师 + 审稿 2 套成人造型与姿态  
- 对话镜头（dialogue camera）轻微 prioritise 角色  
- 语音可选后置  

**验收**：玩家愿意主动找导师，而不是只当钥匙 NPC。

### Phase 3 · 材质与关键资产替换

- 材质包统一；1–2 地标英雄资产  
- 等距/2D 地图模式与加载图  

**验收**：官网可截一张岛图当 hero。

### Phase 4 · 打磨与性能

- 移动端触控、画质档、雾与阴影预算

## 13. 体素风实验（非 Minecraft 品牌）

- **目标**：解决「画面太简单/toy=不够丰富」，不是幼稚化；**不使用** Minecraft 商标、素材、命名。
- **世界**：`VoxelBrick` / `VoxelMass` 台阶构筑、窗格栅、平板屋顶；雷达与栈桥改为方块堆叠。
- **角色**：头/身/肢改为方块 `flatShading`。
- **UI**：HUD/卷宗/地图 banner 改为直角、硬阴影块状面板（自有「研究站体素 UI」语言）。
- **许可边界**：原创体素语法；禁止 MC 资源路径与品牌文案。
